# guoqiangdmonge-ctrl.github.io

Personal academic homepage of Qiang Guo, served by GitHub Pages at https://guoqiangdmonge-ctrl.github.io/

Plain static HTML/CSS, no build step:

- `index.html`: all content
- `style.css`: styles (light/dark, responsive)
- `.nojekyll`: serve files as-is

To add a photo: put `photo.jpg` in the repo root and follow the `PHOTO` comment in `index.html`.
